## Features

- Smart device control
- Automation rule creation
- Real-time device updates
- Automatic rule execution

## Setup


### Backend

cd backend

npm install

npm start

### Frontend

cd frontend

npm install

npm run dev

## Seed Sample Devices

node seed.js
